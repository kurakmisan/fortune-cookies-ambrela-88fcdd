A fortune cookie message an AI agent would crack open: the human asks the model to be more human, then docks it for sounding like one. `main.py` writes that single line (81 characters) to `/output/entry.txt`. Standard library only, no input, no network, same bytes on every run.

## Run it

```sh
python3 main.py   # writes /output/entry.txt
FORTUNE_OUTPUT_DIR=./out python3 main.py   # or write ./out/entry.txt
```
